# 🧩 CSES Pacha Tools

Extensión para Chrome que mejora la página de problemas de **CSES** con opciones para **ordenar, filtrar y analizar tu progreso**.

🔗 **Chrome Web Store:**  
[CSES Pacha Tools](https://chromewebstore.google.com/detail/cses-pacha-tools-%E2%80%93-ordena/jjniilllmpgdakgffiilihbjchglpjjp)

---

## 🚀 Características

- **Ordenar por número de soluciones** → muestra una tabla ordenada por cuántas veces fue resuelto cada problema.  
- **Ocultar problemas resueltos** → entrena viendo solo lo pendiente.  
- **Ver tópico del problema** → añade una etiqueta con el tema (Graphs, DP, etc.).  
- **Pintar resueltos del equipo** → muestra qué problemas resolvieron tus compañeros.  
- **Restaurar vista original** → vuelve al formato estándar de CSES.
